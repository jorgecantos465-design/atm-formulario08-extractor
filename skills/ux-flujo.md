# Skill: UX y flujo - extractor F08 digital

## Objetivo
Mejorar claridad operativa de ejecucion, errores, logs y revision de salida.

## Cuando usarla
Usala para mensajes CLI, instrucciones README, nombres de salida o logs.

## Pasos obligatorios
- Identificar paso confuso.
- Mantener mensajes accionables.
- Indicar archivo afectado.
- No ocultar campos no encontrados.

## Checklist antes de modificar
- Flujo actual probado.
- Usuario operativo definido.
- No cambia logica de extraccion.

## Checklist antes de finalizar
- Mensajes son claros.
- README/logs siguen consistentes.
- Errores ayudan a corregir input/template.

## Errores que debe evitar
- Silenciar errores.
- Usar mensajes tecnicos sin accion.
- Generar output ambiguo.

## Comandos de verificacion
- `npm run extractor`
- `npm test`

## Formato de reporte final
- Paso mejorado.
- Mensajes cambiados.
- Caso probado.
- Riesgos.
